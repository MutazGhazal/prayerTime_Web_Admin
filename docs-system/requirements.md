# وثيقة متطلبات المشروع: تطبيق أوقات الصلاة مع الواتساب

## نظرة عامة على المشروع
تطبيق موبايل يعرض أوقات الصلاة اليومية ويقوم برفعها تلقائياً كحالة (Status) على تطبيق الواتساب.

---

## المتطلبات الأساسية (Core Features)

### 1. عرض أوقات الصلاة
- عرض أوقات الصلوات الخمس (الفجر، الظهر، العصر، المغرب، العشاء)
- تحديث الأوقات يومياً بشكل تلقائي
- دعم التقويم الهجري والميلادي
- حساب أوقات الصلاة بناءً على الموقع الجغرافي للمستخدم

### 2. التكامل مع الواتساب
- رفع أوقات الصلاة اليومية كحالة على الواتساب
- خيار للمستخدم لتحديد توقيت النشر (مثلاً: الساعة 5 صباحاً يومياً)
- تصميم جذاب للحالة مع خلفية إسلامية
- إمكانية تخصيص محتوى الحالة (نص، صورة، أو فيديو قصير)

### 3. الإشعارات
- إشعارات قبل كل وقت صلاة (قابلة للتخصيص)
- إشعار تذكير بعد الأذان
- أذان صوتي (اختياري مع عدة مؤذنين)

---

## المتطلبات التقنية

### المنصات
- Android (أولوية)
- iOS (إن أمكن)

### الأذونات المطلوبة
- الوصول للموقع الجغرافي (GPS)
- الوصول للإنترنت
- الوصول لواجهة الواتساب (WhatsApp API أو Intent)
- إذن الإشعارات
- إذن العمل في الخلفية

### مصادر البيانات
- API لأوقات الصلاة مثل:
  - Aladhan API (مجاني)
  - Islamic Finder API
  - Prayer Times API
- تخزين محلي (SQLite أو SharedPreferences) للبيانات المؤقتة

### التقنيات المقترحة
- **Android**: Kotlin/Java مع Android Studio
- **iOS**: Swift مع Xcode
- **Cross-platform**: Flutter أو React Native (للتطوير الأسرع)
- **خدمة الخلفية**: WorkManager (Android) أو Background Tasks (iOS)

---

## التدفق الوظيفي (Workflow)

### عند فتح التطبيق لأول مرة:
1. طلب أذونات (الموقع، الإشعارات، الوصول للواتساب)
2. تحديد الموقع الجغرافي تلقائياً أو يدوياً
3. اختيار طريقة حساب أوقات الصلاة
4. إعداد تفضيلات الإشعارات
5. إعداد تفضيلات نشر الحالة على الواتساب

### العمل اليومي:
1. تحديث أوقات الصلاة يومياً عند منتصف الليل
2. إرسال إشعارات عند كل وقت صلاة
3. نشر الحالة على الواتساب في الوقت المحدد من المستخدم
4. حذف الحالة القديمة قبل نشر الجديدة (إن أمكن)

---

## واجهة المستخدم (UI/UX)

### الشاشة الرئيسية:
- عرض الوقت الحالي والتاريخ (هجري وميلادي)
- عرض الصلاة القادمة مع الوقت المتبقي
- قائمة بجميع أوقات الصلاة لليوم
- زر سريع لمشاركة أوقات الصلاة

### شاشة الإعدادات:
- تغيير الموقع
- اختيار المؤذن المفضل
- تخصيص الإشعارات
- إعدادات نشر الحالة على الواتساب
- اختيار التصميم/الثيم

### تصميم الحالة للواتساب:
- صورة أو فيديو جذاب مع:
  - أوقات الصلوات الخمس
  - التاريخ الهجري والميلادي
  - آية قرآنية يومية (اختياري)
  - دعاء اليوم (اختياري)

## الميزات الإضافية المقترحة

### المستوى الأول (سهلة التنفيذ):
1. **القبلة**: بوصلة لتحديد اتجاه القبلة
2. **التقويم الإسلامي**: عرض المناسبات الإسلامية
3. **الأذكار**: أذكار الصباح والمساء
4. **أدعية**: مجموعة من الأدعية اليومية
5. **مواقيت الإمساك والإفطار** في رمضان
6. **عداد التسبيح الرقمي**
7. **حفظ أوقات الصلاة للاستخدام دون إنترنت**

### المستوى الثاني (متوسطة الصعوبة):
8. **تسجيل الصلوات**: تتبع الصلوات المؤداة
9. **إحصائيات**: نسبة الالتزام بالصلوات
10. **ثيمات متعددة**: وضع ليلي/نهاري، ألوان مختلفة
11. **لغات متعددة**: العربية، الإنجليزية، الفرنسية، الأردية
12. **تصاميم متعددة للحالة**: اختيار من عدة قوالب
13. **Widget**: عرض أوقات الصلاة على الشاشة الرئيسية
14. **مشاركة مخصصة**: إرسال الأوقات لجهات الاتصال مباشرة
15. **القرآن الكريم**: قراءة واستماع (مكتبة مدمجة)

### المستوى الثالث (متقدمة):
16. **تذكير بالأوراد اليومية**: جدول للعبادات اليومية
17. **مساجد قريبة**: عرض المساجد القريبة على الخريطة
18. **أوقات الصلاة في المساجد**: ربط مع المساجد المحلية
19. **مجتمع**: مشاركة مع الأصدقاء والتشجيع المتبادل
20. **الدروس الدينية**: صوتيات ومقاطع تعليمية
21. **AI للأسئلة الدينية**: مساعد ذكي للإجابة على الأسئلة
22. **وضع السفر**: تغيير الموقع تلقائياً عند السفر
23. **مزامنة عبر الأجهزة**: حفظ البيانات في السحابة
