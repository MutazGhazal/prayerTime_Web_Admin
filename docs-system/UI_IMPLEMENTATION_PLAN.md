# خطة تنفيذ واجهة المستخدم (9:16)

## نظرة عامة
تطبيق التعديلات على واجهة تطبيق أوقات الصلاة وفق الموكب المعتمد، مع إزالة البطاقات المربعة وضبط الألوان والروابط والإعلانات. المعتمد هو **نسبة العرض إلى الارتفاع 9:16** كدلالة على حجم وأبعاد الواجهة.

---

## 1️⃣ ألوان الخلفية — افتتاح الألوان (جميع الثيمات)

**الهدف:** جعل الخلفية أفتح قليلاً مع الحفاظ على القراءة.

| الملف | التعديل |
|-------|---------|
| `lib/presentation/app_background.dart` | تخفيض `opacity` الطبقة البيضاء من `0.75` إلى **`0.65`** أو **`0.6`** |

```dart
// السطر 35 تقريباً
child: Container(color: Colors.white.withOpacity(0.65)),  // بدل 0.75
```

**الملاحظة:** ينطبق على ثيم theme_default و mosque_garden معاً.

---

## 2️⃣ إزالة أشكال البطاقات المربعة (واجهة المستخدم)

**الهدف:** إزالة الإطارات المربعة واستخدام تصميم أبسط ومتناسق مع الخلفية.

| العنصر | الملف | التعديل الحالي | التعديل المطلوب |
|--------|-------|----------------|-----------------|
| كرت الصلاة القادمة | `_NextPrayerCard` | `Container` مع خلفية | تقليل الخلفية أو إزالتها، استخدام نص فقط مع ظل خفيف |
| كرت أوقات الصلاة | `_PrayerTimesList` | `Container` أبيض شفاف | استبدال بـ `Column` أو حاوية بدون إطار |
| أزرار الإجراءات | `_QuickActions` | `Container` بخلفية | أزرار مسطحة بدون إطار مستطيل |
| روابط المحتوى | `_LinkChip` | `Card` | استبدال بـ `InkWell`/`GestureDetector` مع نص + أيقونة فقط |
| كروت الإعلانات | `_ContentCard` | `Card` مع elevation | استبدال بـ `InkWell` مع صورة ونص بدون إطار واضح |
| كرت الموقع والتاريخ | `_HeaderCard` | `Padding` فقط | الحفاظ على التصميم الحالي أو جعله أفتح |

**الخلاصة:** استبدال كل `Card` و `Container` ذات الخلفية الثقيلة بعناصر بسيطة (نص، أيقونات، روابط) بدون إطارات مربعة.

---

## 3️⃣ هيكل الإعلانات والروابط (حسب الموكب)

### توزيع المحتوى

| النوع | العدد | المصدر في قاعدة البيانات | الحقول |
|-------|-------|---------------------------|--------|
| **اعلانات للمستخدم** | 3 | `app_user_sections` أو `client_sections` (section 2) | title, body, image_url, **link_url** |
| **اعلانات للادمن** | 5 | `admin_sections` (section 4) | title, body, image_url, **link_url** |

### قاعدة البيانات
- **`client_sections`**: section 1 (شركة)، 2 (روابط)، 3 (عروض)
- **`admin_sections`**: section 4 (إعلانات أدمن)، 5 (روابط تسويق)
- **`app_user_sections`**: محتوى مخصص للمستخدم (حتى 3 عناصر كـ "اعلانات للمستخدم")

**التعديل المطلوب:** التأكد من أن كل عنصر يحتوي على:
- `title` (عنوان الإعلان)
- `link_url` (الرابط — إلزامي للمشاركة)
- `image_url` (اختياري)

## 4️⃣ عرض العنوان + الرابط عند المشاركة

**الهدف:** عند المشاركة، يظهر النص بصيغة: **"العنوان: الرابط"** لكل إعلان.

### تعديل `_buildFullCaption()` في `home_screen.dart`

**الصيغة الحالية:**
```
🔗 العنوان
الرابط
```

**الصيغة المطلوبة:**
```
عنوان اعلان 1 للمستخدم
https://example.com/link1

عنوان اعلان 1 للادمن
https://example.com/admin1
```

أو بصيغة واحدة للسطر:
```
عنوان اعلان 1 للمستخدم: https://example.com/link1
```

**الخوارزمية:**
1. جمع `userItems` (اعلانات المستخدم) — حتى 3
2. جمع `adminAds` (اعلانات الأدمن) — حتى 5
3. لكل عنصر له `link_url` غير فارغ: إضافة `"${title}\n${linkUrl}"` أو `"$title: $linkUrl"`
4. الاحتفاظ بمشاركة الصورة كما هي عبر `Share.shareXFiles`

## 5️⃣ صفحة المستخدم vs صفحة الأدمن

### صفحة المستخدم (Flutter — home_screen)
- عرض: اعلانات المستخدم (3) + اعلانات الأدمن (5)
- الترتيب حسب الموكب: أعلانات المستخدم أولاً، ثم بطاقة الصلاة، ثم أعلانات الأدمن
- بدون بطاقات مربعة
- المشاركة: صورة + نص (العنوان + الرابط لكل إعلان)

### صفحة الأدمن (web-admin)
- إدارة محتوى `admin_sections` (5 إعلانات)
- إدارة `client_sections` / `app_user_sections` للمستخدمين
- واجهة مشابهة للوكب: نفس الحقول (عنوان، صورة، رابط) مع إمكانية التعديل

**ملاحظة:** صفحة الأدمن غالباً في `web-admin` — يجب مراجعة هيكلها والتأكد من عرض نفس الحقول (title, image_url, link_url) وربطها بالجداول المناسبة.

## 6️⃣ ترتيب التنفيذ المقترح

1. **ألوان الخلفية** — تعديل بسيط في `app_background.dart`
2. **إزالة البطاقات المربعة** — تعديل `home_screen.dart` (الكروت، الروابط، الأزرار)
3. **تعديل نص المشاركة** — `_buildFullCaption()` لتضمين العنوان + الرابط
4. **مراجعة قاعدة البيانات** — التأكد من وجود `link_url` لجميع الإعلانات
5. **مزامنة صفحة الأدمن** — إن لزم، لتتوافق مع هيكل الإعلانات الجديد
